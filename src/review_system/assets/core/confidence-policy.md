# Confidence Policy

- **HYPOTHESIS** — Plausible but not yet supported by a complete reachable path.
- **SUPPORTED** — Reachable path and concrete mechanism are established, but execution reproduction is not complete.
- **CONFIRMED** — Deterministic reproduction or equivalent runtime proof exists.
- **RESOLVED** — Corrective change is verified with targeted and required regression evidence.
- **REJECTED** — The proposed issue was disproved, unreachable, already defended, or outside scope.
